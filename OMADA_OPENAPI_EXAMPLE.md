# Omada Open API: пример подключения

В карте открыть «Поликлиника» → «1-й Этаж» → коммутатор TL_SG3452_1_Left_1 → настройки.

Параметры:
- IP коммутатора: 172.16.16.190;
- метод: TP-Link Omada;
- порт API контроллера: 8043;
- авторизация: Open API — Client ID / Client Secret;
- IP контроллера: 172.16.16.110;
- Controller ID: bc6e128724b0501274a7d26d9321bbd5;
- Site ID: 6a6322ed3a70c0431d082918;
- сайт: tp_sg3452;
- MAC коммутатора: E4:FA:C4:C4:33:8E;
- портов: 52.

В поля Client ID и Client Secret ввести значения клиента Open API с правом Viewer и доступом к этому сайту. Секрет хранится зашифрованным в базе и не возвращается браузеру. При замене клиента заполнить оба поля заново, сохранить и выполнить «Опросить». Пустой секрет при сохранении оставляет прежнее значение. ID контроллера, сайта и MAC коммутатора при замене API-клиента сохраняются.

Для HTTPS настроен доверенный публичный сертификат именно этого контроллера. Проверка сертификата не отключена глобально. Если сертификат контроллера сменится, заменить PEM в разделе «Доверенный сертификат контроллера». NETWORK_ALLOWED_CIDRS на сервере разрешает адреса контроллера и коммутатора.

Open API возвращает клиентов сайта: их MAC, IP, switchMac и port. Приложение читает все страницы и оставляет только активные подключения к выбранному коммутатору. Это список клиентов контроллера, а не полный SNMP forwarding table: транзитные MAC и скрытые контроллером устройства могут отсутствовать.

Чтобы определить кабинет техники, выбрать порт в карточке коммутатора и назначить реальный кабинет. В карточке техники заполнить её MAC. После опроса совпадение MAC на однозначном порту переносит технику в назначенный кабинет. Кабинеты портам этого коммутатора не назначались без фактической схемы разводки.

SNMP v2c — отдельный способ прямого чтения коммутатора. Для него выбрать метод SNMP, IP 172.16.16.190, порт 161 и community из настроек Omada. Перенаправление веб-интерфейса на контроллер не запрещает SNMP. Для SNMPv3 одного имени snmp недостаточно: также нужны уровень защиты, auth/priv протоколы и ключи; текущий SNMP-адаптер проекта работает с v2c.
