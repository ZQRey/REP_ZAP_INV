# Развёртывание изменений карты

Обновить приложение и выполнить миграцию `alembic upgrade head` (добавляет описание помещения). В Docker Compose миграция запускается отдельным сервисом перед приложением и новым `network-worker`.

Фоновый поиск: `python -m SHARED.network_worker`, период `NETWORK_POLL_SECONDS`, по умолчанию 60 секунд. Docker Compose запускает worker автоматически. Для прямого подключения доступны SNMP v2c и SSH; для Omada указать адрес контроллера, сайт, учётные данные и MAC конкретного коммутатора. API контроллера должен возвращать switchMac у клиентов; совместимость с установленной версией контроллера требует проверки в сети.

На плане нажать «Разметить кабинет» или «Разметить коридор», отметить минимум три угла, заполнить название, номер и описание, сохранить. Нажатие на помещение открывает описание, технику и назначенные порты. Поля можно изменить через «Редактировать помещение».

Перетаскивание техники на полигон назначает помещение. В карточке порта коммутатора указать помещение назначения; для сопоставления в технике должен быть заполнен MAC. Перенос выполняется только для уникального MAC и порта с одним обнаруженным MAC. Перенос между филиалами выполняет фоновый worker либо супер администратор; администратор филиала работает в своём филиале. События записываются в историю техники. Отключённое устройство может быть найдено после повторного подключения к сети.

SNMP использует Bridge-MIB; если нумерация bridge-port отличается от физической нумерации, в extra_params.ifindex_port_map задаётся соответствие ifIndex -> физический порт. Порты с несколькими MAC (uplink) не используются для автоматического определения кабинета.

Сбор ПК из AD теперь использует ту же настройку ad_allow_plaintext, что и LDAP-вход. Без явного разрешения plaintext используется TLS.
